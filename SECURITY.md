# Security Policy

## Supported versions

This is a personal fork of the [money](https://github.com/powerpaul17/nc_money) Nextcloud app,
maintained by [EventideMiles](https://github.com/EventideMiles) and sideloaded on a single
instance. Only the latest `master` of this fork is supported — upstream releases and other
branches are not.

## Reporting a vulnerability

Please do **not** open a public issue for security problems.

Report privately via a [GitHub security advisory](https://github.com/EventideMiles/nc_money/security/advisories/new)
on this repository. If you cannot use advisories, contact the owner
([@EventideMiles](https://github.com/EventideMiles)) through GitHub directly.

There is **no SLA** — this is a hobby project — but reports will be reviewed and credited
on request.
